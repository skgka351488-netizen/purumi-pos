# 푸르미 문구점 바코드 POS 시스템 (Purumi Store POS)

학교 행사에서 학생들이 모은 **칭찬 적립금**을 교환한 **율천 화폐(지류 화폐)**로 문구류를 구매할 수 있도록 지원하는 초간결 단일 PC 바코드 POS 웹 애플리케이션입니다.

본 프로젝트의 UI/UX는 **토스 디자인 시스템(TDS, Toss Design System)**의 색상 팔레트, 타이포그래피, 버튼 및 카드 인터랙션 가이드를 준수하여 제작되었습니다.

---

## 🌟 주요 특징

1. **토스 디자인 시스템(TDS) 스타일 적용**:
   - Primary Blue (`#3182f6`) 중심의 직관적이고 깔끔한 금융/결제 인터페이스.
   - Pretendard & Toss Product Sans 기반의 가독성 높은 타이포그래피.
   - 터치 및 키보드 반응형 인터랙션 (Active scale 애니메이션).
2. **USB 바코드 리더기 최적화**:
   - 바코드 스캐너(HID 키보드 에뮬레이션) 입력 포커스 자동 유지.
   - 스캔 즉시 장바구니에 품목 자동 추가 및 중복 스캔 시 수량 `+1`.
3. **율천 화폐 전용 결제 및 거스름돈 계산기**:
   - 율천 화폐 단위(+100율, +500율, +1,000율, +2,000율, +5,000율, 딱 맞게) 빠른 버튼 제공.
   - 받은 금액에 따른 거스름돈 실시간 계산 및 시각적 피드백(충분: 녹색, 부족: 적색).
   - 단축키 지원: `Enter` / `F2` (결제 완료), `ESC` (장바구니 초기화/모달 닫기).
4. **오프라인 퍼스트 (브라우저 로컬 구동)**:
   - 인터넷 연결 없이 브라우저 단독 실행 가능 (LocalStorage 기반 데이터 영속화).
   - 상품 등록/수정/삭제 관리 기능 내장.
   - 오늘의 매출 집계(총 매출액, 결제 건수, 결제 취소) 및 엑셀(CSV) 내보내기 지원.

---

## 🚀 실행 방법

별도의 서버 설치 없이 브라우저에서 바로 열어 사용할 수 있습니다.

1. 저장소를 클론하거나 다운로드합니다.
2. `index.html` 파일을 더블 클릭하여 Chrome, Edge 등의 최신 웹 브라우저로 엽니다.
3. USB 바코드 리더기를 PC에 연결한 뒤 상품 바코드를 스캔하여 바로 결제를 진행합니다.
